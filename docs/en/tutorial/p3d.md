# Prepar3D (P3D) Online Flight Tutorial

This tutorial covers Prepar3D (P3D) and explains how to connect to the XFLYSIM online flight server.

## Preparation

### 1. Install the flight simulator

- Purchase and install Prepar3D from the [Prepar3D website](https://www.prepar3d.com).
- Make sure it is updated to the latest version and complete the basic flight training (or get familiar with the basic operations).

### 2. Install the online flight client

- Download and install the XFLYSIM online flight client.
- Enter the account and callsign registered on the online flight website.

### 3. Install the voice software

- Voice crews need to install **XVoice** voice software (see the [XVoice tutorial](/en/tutorial/xvoice)).
- Text-based crews can skip this step and communicate via text in the game.

## Connecting

1. Launch Prepar3D and select the aircraft and airport you want to fly.
2. Park the aircraft at a **fixed parking stand** and wait for it to finish loading.
3. Start the online flight client, enter your callsign and connect to the server `ol.xflysim.com`.
4. After connecting, submit your flight plan as soon as possible (departure/arrival airports, cruise flight level, planned route, aircraft type, etc.).
5. In airspace without ATC services, use the public frequency 122.800; when a controller is online, follow their instructions.

## Notes

- Connecting directly on taxiways, runways or other non-stand positions is strictly prohibited.
- Please carefully read the [User Guidelines](/en/rules/user-rules) before flying.
- In controlled airspace, listen to ATC instructions and observe the "left-window yield principle".
