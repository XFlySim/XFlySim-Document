# 連線教程

歡迎來到 XFLYSIM 連飛！本教程將幫助你完成第一次連線飛行。

## 快速開始

### 1. 註冊賬號與呼號

- 在連飛網站註冊賬號，並申請一個有效呼號。
- 呼號是你連入伺服器後的唯一標識，請妥善保管，**不要將賬號借與他人使用**。

### 2. 準備軟體

你需要準備以下軟體：

| 用途 | 說明 |
| --- | --- |
| 飛行模擬軟體 | 如 Microsoft Flight Simulator、X-Plane 等 |
| 連飛客戶端 | 用於連線 XFLYSIM 連飛伺服器 |
| XVoice | 語音通訊軟體，語音機組連線管制時需要 |
| 連飛地圖 | 用於檢視當前飛行空域內是否有管制員線上 |

### 3. 連線伺服器

- 伺服器地址：`ol.xflysim.com`
- 請**在機場設定的固定停機位**連入伺服器，嚴禁在滑行道、跑道上等非停機位直接連線。
- 連線伺服器後，應當**第一時間提交有效的飛行計劃**（包含起降機場、巡航高度層、計劃航路、機型等）。

### 4. 通訊頻率

- 自行連飛沒有管制員時，請使用**公用頻率 122.800**。
- 管制員上線時會在公用頻道使用文字呼叫（`Please contact me on XXX.XX`），此時請將通訊面板調至管制員相應的頻率，與管制員建立聯絡。
- **文字機組**：在遊戲內直接文字交流即可。
- **語音機組**：需要連線 XVoice 語音軟體。

### 5. 正式飛行

在管制空域內請遵從管制員指揮，注意"左窗避讓原則"，並在飛行前仔細閱讀[使用者準則](/rules)。

## 常見問題

### 應答機如何設定？

進入起飛跑道至脫離落地跑道期間置於 C 模式，其餘時間置於 S 模式，僅在管制員要求識別時使用 IDENT 模式。

### 什麼是掛機飛行？

指連線到伺服器但無法對管制員或監察員指令做出回應的狀態，例如外出用餐、睡眠等。活動期間嚴禁掛機飛行。

### 緊急程式碼如何使用？

連飛禁止使用 7500、7600 程式碼，如確有故障可以掛出 7700，正常情況禁止亂掛。
