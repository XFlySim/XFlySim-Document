# Prepar3D（P3D）連線教程

本教程適用於 Prepar3D（P3D），介紹如何連入 XFLYSIM 連飛伺服器。

## 準備階段

### 1. 安裝飛行模擬軟體

- 透過 [Prepar3D 官網](https://www.prepar3d.com) 購買並安裝 Prepar3D。
- 確認已安裝最新版本，並完成基礎飛行訓練（或熟悉基本操作）。

### 2. 安裝連飛客戶端

- 下載並安裝 XFLYSIM 連飛客戶端。
- 在客戶端中填寫連飛網站註冊的賬號與呼號。

### 3. 安裝語音軟體

- 語音機組需要安裝 **XVoice** 語音軟體（詳見 [XVoice 語音教程](/tutorial/xvoice)）。
- 文字機組可跳過此步驟，在遊戲內直接使用文字交流。

## 連線步驟

1. 開啟 Prepar3D，選擇需要飛行的機型和機場。
2. 將飛機停放在**固定停機位**，等待載入完成。
3. 啟動連飛客戶端，填入呼號並連線伺服器 `ol.xflysim.com`。
4. 連線成功後，第一時間提交飛行計劃（起降機場、巡航高度層、計劃航路、機型等）。
5. 在未提供管制服務的空域，使用公用頻率 122.800；有管制員線上時聽從其指揮。

## 注意事項

- 嚴禁在滑行道、跑道上等非停機位直接連線。
- 飛行前請仔細閱讀[使用者準則](/rules)。
- 管制空域內注意收聽管制員指令，遵守"左窗避讓原則"。
