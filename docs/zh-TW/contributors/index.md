## 參與方式

歡迎所有社群成員參與文件建設：

- **提交問題** — 發現文件錯誤或有疑問，請提交 [Issue](https://github.com/XFlySim/XFlySim-Document/issues)。
- **參與編寫** — 頁面底部提供「在 GitHub 上編輯此頁面」入口，可直接修改。
- **翻譯校對** — 文件支援簡體中文、繁體中文、English 三種語言，歡迎幫忙校對與完善。

所有貢獻內容均以 [MIT 許可證](https://github.com/XFlySim/XFlySim-Document/blob/main/LICENSE) 授權。
