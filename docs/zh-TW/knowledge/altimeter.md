# 過渡高度與高度表撥正（QNH/QFE/QNE）

> 本頁內容整理自公開資料，僅供學習參考；具體數值以現行有效的《航行資料彙編》及機場資料為準。

## 高度表的三種基準

高度表顯示的高度取決於氣壓基準，常見的三種撥正方式為：

| 撥正值 | 含義 | 高度表指示 |
| --- | --- | --- |
| **QNH** | 修正海平面氣壓 | 修正海平面高度（近似於海拔高度） |
| **QFE** | 場面氣壓 | 相對機場標高的高度 |
| **QNE** | 標準大氣壓（1013.25 hPa / 29.92 inHg） | 氣壓高度，過渡高度層以上統一使用 |

## 過渡高度與過渡高度層

- **過渡高度（TA，Transition Altitude）**：在終端區內飛至該高度後，須將高度表由 QNH 撥正為 QNE，此後高度以飛行高度層（FL）表示。中國大陸多數地區過渡高度為 **3000 米**，高原等高海拔機場另有調整，以機場資料為準。
- **過渡高度層（TL，Transition Level）**：標準氣壓面上第一個可使用的飛行高度層。中國大陸多數地區為 **3600 米**（約相當於 FL118）。
- 過渡高度與過渡高度層之間的部分稱為**過渡夾層**，其中禁止穿越，以保證由機場氣壓向標準氣壓過渡時的垂直間隔。

## 飛行高度層

超過過渡高度層後，高度以**飛行高度層（FL）**表示：高度表撥正至 QNE，按「高度英尺數 ÷ 100」取值，例如 FL118 表示 11800 英尺。

米制與英尺的換算關係為 1 米 = 3.28084 英尺。中國民航巡航高度層以米制填寫，兩者的對照可參考[中國民航實施縮小垂直間隔（RVSM）與米制飛行高度層](/zh-TW/knowledge/rvsm)。

## 連線飛行的應用

1. 進近、離場階段使用管制員指定的機場 QNH（或按要求使用 QFE）設定高度表。
2. 巡航階段高度表撥正至 QNE，並按管制員指令使用飛行高度層。
3. 由中國大陸地區起飛的航空器，飛行計劃中的巡航高度層須按中國民航 RVSM 高度層配備規則填寫（見[使用者準則](/zh-TW/rules/user-rules)）。
