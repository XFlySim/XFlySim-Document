## 参与方式

欢迎所有社区成员参与文档建设：

- **提交问题** — 发现文档错误或有疑问，请提交 [Issue](https://github.com/XFlySim/XFlySim-Document/issues)。
- **参与编写** — 页面底部提供「在 GitHub 上编辑此页面」入口，可直接修改。
- **翻译校对** — 文档支持简体中文、繁體中文、English 三种语言，欢迎帮忙校对与完善。

所有贡献内容均以 [MIT 许可证](https://github.com/XFlySim/XFlySim-Document/blob/main/LICENSE) 授权。
