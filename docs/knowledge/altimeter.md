# 过渡高度与高度表拨正（QNH/QFE/QNE）

> 本页内容整理自公开资料，仅供学习参考；具体数值以现行有效的《航行资料汇编》及机场资料为准。

## 高度表的三种基准

高度表显示的高度取决于气压基准，常见的三种拨正方式为：

| 拨正值 | 含义 | 高度表指示 |
| --- | --- | --- |
| **QNH** | 修正海平面气压 | 修正海平面高度（近似于海拔高度） |
| **QFE** | 场面气压 | 相对机场标高的高度 |
| **QNE** | 标准大气压（1013.25 hPa / 29.92 inHg） | 气压高度，过渡高度层以上统一使用 |

## 过渡高度与过渡高度层

- **过渡高度（TA，Transition Altitude）**：在终端区内飞至该高度后，须将高度表由 QNH 拨正为 QNE，此后高度以飞行高度层（FL）表示。中国大陆多数地区过渡高度为 **3000 米**，高原等高海拔机场另有调整，以机场资料为准。
- **过渡高度层（TL，Transition Level）**：标准气压面上第一个可使用的飞行高度层。中国大陆多数地区为 **3600 米**（约相当于 FL118）。
- 过渡高度与过渡高度层之间的部分称为**过渡夹层**，其中禁止穿越，以保证由机场气压向标准气压过渡时的垂直间隔。

## 飞行高度层

超过过渡高度层后，高度以**飞行高度层（FL）**表示：高度表拨正至 QNE，按“高度英尺数 ÷ 100”取值，例如 FL118 表示 11800 英尺。

米制与英尺的换算关系为 1 米 = 3.28084 英尺。中国民航巡航高度层以米制填写，两者的对照可参考[中国民航实施缩小垂直间隔（RVSM）与米制飞行高度层](/knowledge/rvsm)。

## 连线飞行的应用

1. 进近、离场阶段使用管制员指定的机场 QNH（或按要求使用 QFE）设定高度表。
2. 巡航阶段高度表拨正至 QNE，并按管制员指令使用飞行高度层。
3. 由中国大陆地区起飞的航空器，飞行计划中的巡航高度层须按中国民航 RVSM 高度层配备规则填写（见[用户准则](/rules/user-rules)）。
