# XVoice 语音软件全套教程


## 一、介绍 - 免费专业级模拟飞行及综合语音

- **驾驶舱交互联动!** 频道切换, 音量调节及通讯开关全部在驾驶舱内操作调节。
- **CVR驾驶舱语音记录仪!** 保存复盘每一次飞行通讯。
- **AI智能副驾!** 切换频率, 音量, 收听开关只需要下达你的命令, 交给AI副驾帮你执行。
- **文字转语音, 语音转文字!** 繁忙的时候眼睛负责监控飞行, 聊天内容交给耳朵。
- **真实无线电效果!** 根据真实陆空无线电语音效果进行细致调整, 保障通讯清晰基础上完美复现陆空通讯效果。
- **三频道同时收听!** 支持双频道(COM1,COM2)+自定义频道同时收听. 智能识别优先收听。
- **热键绑定/回声消除/降噪/自动增益!**支持键盘, 鼠标, 手柄及飞行操纵杆等外设进行语音热键绑定。 同时支持回声消除/降噪/自动增益等功能。
- **通讯距离阈值!** 根据语音双方距离的不同, 通讯清晰度也会有所不同。
- **领先的语音编码压缩和通讯加密技术**，确保XVoice语音服务端在低配置服务器上亦能安全流畅传输每一份语音数据包。

> XVoice的诞生 - 填补了模拟飞行专用语音通讯领域的空白; 提供了软硬件训练模拟器语音通讯领域最完整且最优化的解决方案; 解决了众多模拟飞行平台产品开发中语音通讯模块的难题。

## 三、常见问题

### **1. XVoice for Mac 安装说明 (非 Mac App Store 版本)**

<iframe src="//player.bilibili.com/player.html?isOutside=true&aid=116898943470081&bvid=BV1kYNs6sEn5&cid=39838878522&p=1" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="100%" height="500"></iframe>

由于本软件暂未在 Apple 进行开发者签名，**首次打开时系统可能会提示“软件已损坏”或无法打开。请按照以下步骤解除系统限制：**

​            1.     下载安装包（.zip 或 .dmg）。

​            2.     解压或打开磁盘映像，将 XVoice.app 拖入到 **应用程序 (Applications)** 文件夹中。

​            3.     按下 Command + 空格 打开聚焦搜索，输入 **终端** (或 Terminal) 并回车打开。

​            4.     复制并粘贴以下命令到终端中，然后按回车：

```
sudo xattr -cr (XVoice.app 拖进终端)
```

​            5.     系统会要求输入你的 Mac 登录密码（**输入时屏幕不会显示字符**，输入完成后直接按回车）。

​            6.     完成后，双击 XVoice 即可正常运行。



### 2.机组通讯问题:

1. **开启机组通讯后, 通讯置顶面板显示异常?** 答: 进入驾驶舱内再开启机组通讯.
2. **自己发言对方听不到?** 答: 检查置顶面板是否激活开启VHF发言.
3. **对方发言自己手听不到?** 答: 检查置顶面板是否开启VHF收听和检查收听音量.
4. **通讯过程中面板显示异常?** 答: 不要在通讯过程中切换机模, 如果切换需要结束并重新开启机组通讯.

### 4.管制员常见问题

- #### **可以在多管制区使用相同的无线电频率吗?**

可以. 相同频率支持多管制地域使用, 但同地域的相同频率只允许一种席位使用. 例如: KLAX的离场与ZBAA的离场同时可以使用118.025管制频率, 但是ZBAA或者KLAX的除离场正在使用以外的其他席位无法再使用118.025频率.

- #### **一位管制员可以进行多频率联管吗?**

可以. 一位管制员最多可以同时对两个频率进行航空管制, 在还原真实管制环境基础上取消了对同管制区域的限制, 这对于管制人员不足及中小平台尤为友好. 例如: 管制员A可以同时对ZBAA的离场和ZSSS的进近进行联管.
