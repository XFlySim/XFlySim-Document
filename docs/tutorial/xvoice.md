# XVoice 语音教程

本教程介绍如何使用 XVoice 语音软件进行语音通讯。

## XVoice 是什么

XVoice 是 XFLYSIM 连飞平台的语音通讯软件。在提供管制服务的空域，语音机组需要使用 XVoice 与管制员及其他机组进行语音通讯。

## 安装与登录

1. 下载并安装 XVoice 客户端。
2. 使用连飞网站注册的账号密码登录。

## 连接服务器

1. 打开 XVoice，选择 XFLYSIM 服务器并连接。
2. 连接成功后，确认软件显示已上线状态。

## 使用注意事项

- 语音机组连入管制空域后，听从管制员指挥并保持语音畅通。
- 活动期间，活动空域内的所有航空器驾驶员必须具有双向语音通讯能力。
- 不方便语音通讯的机组，平台提供英文文字管制服务。
- 请文明用语，和谐沟通。不得辱骂机组或管制员，一经发现直接永久停飞处理。
