# 连线教程

欢迎来到 XFLYSIM 连飞！本教程将帮助你完成第一次连线飞行。

## 快速开始

### 1. 注册账号与呼号

- 在连飞网站注册账号，并申请一个有效呼号。
- 呼号是你连入服务器后的唯一标识，请妥善保管，**不要将账号借与他人使用**。

### 2. 准备软件

你需要准备以下软件：

| 用途 | 说明 |
| --- | --- |
| 飞行模拟软件 | 如 Microsoft Flight Simulator、X-Plane 等 |
| 连飞客户端 | 用于连接 XFLYSIM 连飞服务器 |
| XVoice | 语音通讯软件，语音机组连线管制时需要 |
| 连飞地图 | 用于查看当前飞行空域内是否有管制员在线 |

### 3. 连接服务器

- 服务器地址：`ol.xflysim.com`
- 请**在机场设置的固定停机位**连入服务器，严禁在滑行道、跑道上等非停机位直接连线。
- 连接服务器后，应当**第一时间提交有效的飞行计划**（包含起降机场、巡航高度层、计划航路、机型等）。

### 4. 通讯频率

- 自行连飞没有管制员时，请使用**公用频率 122.800**。
- 管制员上线时会在公用频道使用文字呼叫（`Please contact me on XXX.XX`），此时请将通讯面板调至管制员相应的频率，与管制员建立联系。
- **文字机组**：在游戏内直接文字交流即可。
- **语音机组**：需要连接 XVoice 语音软件。

### 5. 正式飞行

在管制空域内请遵从管制员指挥，注意"左窗避让原则"，并在飞行前仔细阅读[用户准则](/rules/user-rules)。

## 常见问题

### 应答机如何设置？

进入起飞跑道至脱离落地跑道期间置于 C 模式，其余时间置于 S 模式，仅在管制员要求识别时使用 IDENT 模式。

### 什么是挂机飞行？

指连接到服务器但无法对管制员或监察员指令做出回应的状态，例如外出用餐、睡眠等。活动期间严禁挂机飞行。

### 紧急代码如何使用？

连飞禁止使用 7500、7600 代码，如确有故障可以挂出 7700，正常情况禁止乱挂。
