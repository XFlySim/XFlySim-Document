# X-Plane 11/12 连线教程

本教程适用于 X-Plane 11 与 X-Plane 12，介绍如何连入 XFLYSIM 连飞服务器。

## 准备阶段

### 1. 安装飞行模拟软件

- 通过 Steam 或 Laminar Research 官网购买并安装 X-Plane 11 / 12。
- 建议更新至最新版本，保证与连飞客户端兼容。

### 2. 安装连飞客户端

- 下载并安装 XFLYSIM 连飞客户端。
- 在客户端中填写连飞网站注册的账号与呼号。

### 3. 安装语音软件

- 语音机组需要安装 **XVoice** 语音软件（详见 [XVoice 语音教程](/tutorial/xvoice)）。
- 文字机组可跳过此步骤，在游戏内直接使用文字交流。

## 连接步骤

1. 打开 X-Plane，选择需要飞行的机型和机场。
2. 将飞机停放在**固定停机位**，等待加载完成。
3. 启动连飞客户端，填入呼号并连接服务器 `ol.xflysim.com`。
4. 连接成功后，第一时间提交飞行计划（起降机场、巡航高度层、计划航路、机型等）。
5. 在未提供管制服务的空域，使用公用频率 122.800；有管制员在线时听从其指挥。

## 注意事项

- 严禁在滑行道、跑道上等非停机位直接连线。
- 飞行前请仔细阅读[用户准则](/rules)。
- 管制空域内注意收听管制员指令，遵守"左窗避让原则"。
